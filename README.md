# Complex RPG
the successor to https://github.com/jaduplansti/simplestRPG

# Installation
go to the latest releases and download the apk from there.

https://github.com/jaduplansti/complexRPG/releases

# Building From Source
```
git clone https://github.com/jaduplansti/complexRPG
cd complexRPG
pip install flet[all]
flet build apk
```
